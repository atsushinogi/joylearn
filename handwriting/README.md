# もじのアトリエ

`dist/index.html` をブラウザで開きます。ビルドやAPIキーは不要です。全ファイルを同じ構成で配信すれば静的サイトとして動きます。認識エンジンと約6.4 MBの参照パターンを同梱し、外部通信なしで使えます。

指・ペン・マウスで1文字を書き、候補を選択してテキストに追加します。漢字・ひらがな・カタカナの絞り込み、1画戻す、書き直し、編集、コピーに対応。文字は保存しません。筆跡、入力文字は外部送信しません。

認識対象は Kanji Canvas の収録パターンに限られます。くずし字や小文字などの類似字形では正しい候補が出ない場合があります。文字を枠いっぱいに1文字ずつ書いてください。

認識ライブラリ: https://github.com/asdfjkl/kanjicanvas （MIT）。変更せず vendor に収録。元の描画処理は使わず、アプリ側の Pointer Events で入力し認識関数に筆跡を渡しています。ライセンスは dist/vendor/LICENSE.txt に収録。
