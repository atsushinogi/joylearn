# ヒロアカ漢字53問・配布版

[画像付き一覧](index.html) ／ [問題](問題.md) ／ [解答](解答.md)

- PNGと可逆WebPはそれぞれ53枚、すべて200×200px。
- 全53読みを網羅し、問題文に登場する異なる人物は46人。
- 本編第1〜431話の23編から出題。映画・外伝等は含みません。
- 調査は全431話の詳細な公開二次解説と公式資料によるもので、原作全巻の直接閲覧ではありません。
- [章別確認メモ](research/章別確認メモ.md) ／ [出典・出題配分](research/出典と出題配分.md)
- [元教材の読み](research/原教材53読み.csv) ／ [採用画像の生成入力](image-prompts.json)

`originals/` は採用した生成原画、`png/` と `webp/` が配布画像です。一覧の表示・保存はWebPを使い、画像を押すと200×200pxのWebP画像を開けます。全画像を問題・人物・時期・動作と照合し、13件を初稿から修正しました。小さな正規の校章・体操着の幾何模様を除き、解答や説明の文字は画像に入れていません。
