# 漢字のものがたり（手書き53問）

[アプリを開く](index.html)。呪術廻戦・僕のヒーローアカデミアから一作品を選び、各作品の全53問を、イラストを見ながら解きます。問題番号順・シャッフルを選べます。

## 回答と採点

指・ペン・マウスで漢字を1文字ずつ書き、認識候補を選んで回答に追加します。`kanji-test` と同じ Kanji Canvas と手書き入力アダプターを同梱しています。キーボード入力にも対応します。

原教材の対象漢字だけが解答欄です。送りがなや対象外の漢字は問題文に表示済みです。例えば「仏壇」は「□壇」と表示して「仏」、「持て余す」は「持て□す」と表示して「余」だけを入力します。最後にまとめて採点し、間違えた問題だけを復習できます。1問1点、全空欄の一致で正解とし、100点満点へ換算します。字形・書き順の採点ではありません。

作品ごとの回答と位置を、このブラウザーの localStorage に自動保存します。「保存して作品選択へ」で他の作品へ切り替えられます。再読み込み後は「つづきから」で再開できます。保存を使えない環境でも学習は可能です。筆跡や回答は外部へ送信しません。

## 開発とデータ更新

リポジトリーのルートで `python3 -m http.server 8000` を実行し、`http://localhost:8000/kanji-50/` を開きます。アプリは静的ファイルのみで動き、`index.html` の直接表示にも対応します。

- `node kanji-50/scripts/build-app-data.cjs`：両作品の `workbook.json` から、各53問・読み・送りがな・画像パスを検証して `question-bank.js` を生成。
- `node --test kanji-50/tests/*.cjs`：送りがなの分割、採点、出題・復習、保存データの復元と教材対応を検証。
- `node --check kanji-50/app.js`：画面制御の構文チェック。

教材を編集したらデータを再生成してください。公開時はアプリのJS・CSS・`vendor/` と、呪術廻戦の `exports/v2/webp/` とヒロアカの `exports/v1/webp/` 各53枚も配置します。生成したデータは直接編集しません。

`vendor/` の認識エンジンと参照データは既存の Kanji Canvas を改変せずコピーしています。[MITライセンス](vendor/LICENSE.txt)を同梱しています。

## 作品別の教材

作品別の教材は、次のフォルダーにまとめています。

- [呪術廻戦](jujutsu-kaisen/index.html) — [使い方・構成](jujutsu-kaisen/README.md)
- [僕のヒーローアカデミア](my-hero-academia/index.html) — [使い方・構成](my-hero-academia/README.md)

どちらも `originals/`・`research/`・`review/` を持ち、配布版にPNG・WebP・問題・解答・対応CSV・一覧・ZIPを収録しています。呪術廻戦の現行版は `exports/v2/`（600×400px、吹き出しなしの創作セリフ付き）、ヒロアカは `exports/v1/` です。作品ごとの出題範囲と確認方法は、それぞれのREADMEを参照してください。

呪術廻戦の教材は `jujutsu-kaisen/` にまとめています。従来の問題ファイルからの案内リンクも、このフォルダーへ統一しています。
