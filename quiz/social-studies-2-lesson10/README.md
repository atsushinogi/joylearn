# 社会 第10回 歴史めぐりクイズ

[クイズを開く](index.html) ／ [トップページ](../../index.html)

鎌倉から江戸初期までの全60問に、148×148pxのWebP選択肢画像240枚を組み込んだ4択クイズです。`index.html` をブラウザーで開くだけで使えます。ビルド・インストール・外部通信は不要です。

- 10問・20問・全60問から出題数を選択。問題番号順またはランダムに出題します。
- 選択肢は毎回シャッフルし、回答後に正解・解説・得点を表示します。
- 最後に結果を表示し、間違えた問題だけを繰り返し復習できます。
- 「全60問をおさらい」で答えと解説を開き、問題・選択肢・読み・解説から検索できます。
- タブは左右矢印キー・Home・Endで切り替えられます。回答ボタンなどはTab・Enter・Spaceで操作できます。

アプリは `index.html`、`style.css`、`app.js`、`quiz-data.js`、`choice-images.js`、`icon-assets/webp-148/` で構成します。`choice-images.js` は問題データの元の並びと画像を対応づけ、シャッフル時も選択肢と画像を一緒に移動します。FTP同期が全240枚を検出できるよう、画像パスをリテラルで列挙しています。既存の問題データと画像制作ファイルは保持しています。

## アプリの検証

リポジトリのルートで `node quiz/social-studies-2-lesson10/verify.cjs` を実行すると、実際のアプリコードをDOM代替環境で検証します。全60問・240枚の対応、全問正解・全問不正解、10問・20問・60問モード、問題番号順、二重回答・未回答遷移の防止、繰り返し復習、再挑戦、タブのキー操作、全問一覧、検索を確認しています。検証スクリプトはFTP同期の対象外です。

別途、WebP全240枚のデコード・148×148pxの寸法、元問題データのハッシュ一致、HTML構造とARIAの参照先、ローカルリンク、FTP同期へのアプリ245ファイルの収録を確認しました。この環境にはブラウザーがないため、ブラウザーでの表示確認は未実施です。サーバーへのアップロードは行っていません。

## 4択問題データ

[一行問題.txt](一行問題.txt) の全60問から、正解1つ・不正解3つ、計240選択肢を作成しました。元の番号・順序・解答を保持し、漢字を含む選択肢には読みを、全問に回答後の短い解説を付けています。

誤答には関連する人物・出来事・制度などを選び、同義語や正解の別名が別の選択肢に入らないようにしています。正解の位置は1〜4番に各15問ずつ分散しています。

## データ形式

各問は `id`（元の番号）、`q`（問題文）、`options`（4つの選択肢）、`explanation`（解説）、`source`（元問題の参照）を持ちます。

各選択肢の `label` は表示文字列、`furigana` は読みです。カタカナだけの選択肢では読みを省略しています。`correct: true` の選択肢が1つだけあり、不正解の選択肢では `correct` を省略しています。CSVの正解位置は **1始まり** です。

アプリ側で選択肢を並べ替える場合は、`label`・`furigana`・`correct` を同じオブジェクトとして移動してください。既存の画像付きアプリに組み込む場合は、対応する選択肢画像と画面側の設定を別途用意します。
