# ばねと浮力の実験ノート

写真の教材をもとにした、暗算で解ける4択クイズです。`index.html` をブラウザーで開くと使えます。インストール・ビルド・ネット接続は不要です。

- 全24種類（ばね11種類、浮力13種類）。「すべて」を一巡すると、教材の関連図19組をすべて扱います。
- 出題するたびに数値と選択肢の順序を変更。同じ種類を繰り返すときも、直前と異なる条件を作ります。
- 1問ごとに正解判定と計算の解説を表示。答え直しによる二重加点はありません。
- 一巡後に結果を表示し、間違えた問題だけを新しい数値で練習できます。
- 「図の一覧」から元の写真を確認し、特定の図だけを練習できます。
- 図は数値に合わせたSVGで表示。元の写真は参考表示として区別し、古い数値との混同を防いでいます。
- マウス・キーボード・タッチ操作に対応。学習履歴はページを閉じると消えます。

## 数値と物理の扱い

力の単位は教材の表記に合わせたg重です。水の密度は1 g/cm³。整数になる条件から選び、1桁の乗除算や扱いやすい整数の加減算で答えられるようにしています。ばね・糸・棒の重さ、滑車の摩擦、空気から受ける浮力を無視します。台ばかりの問題では水がこぼれないものとします。ばねの図は模式図で、画面上の長さの比から測定する問題ではありません。

## ファイルと確認

- `index.html`、`style.css`：画面とレイアウト
- `questions.js`：出題条件、4択、解説、採点
- `diagrams.js`：数値に連動するSVGの図
- `app.js`：コース、進行、答え合わせ、結果、参考図
- `assets/*.webp`：写真から切り出した19組の参考図

```sh
node --check questions.js
node --check diagrams.js
node --check app.js
node --test tests/*.cjs
```

ブラウザー確認はPythonのPlaywrightとChromiumを用意して実行します。

```sh
python3 tests/browser.py
```

24種類の採点、19組の参考画像、解説、二重加点の防止、結果、間違いの再練習、コース変更、数値の再生成、キーボードとタッチ操作、幅320pxと390pxの表示を確認します。`SPRING_TEST_URL` で確認するURL、`SPRING_SCREENSHOT_DIR` でスクリーンショットの保存先を指定できます。

HTTPサーバーを使う場合は、このフォルダーで `python3 -m http.server 8000` を実行し、`http://localhost:8000/` を開いてください。公開に必要なのはHTML、CSS、3つのJavaScriptと`assets/`の19枚です。参考画像のパスはJavaScript内に明記しており、標準のFTP同期でも19枚を検出します。公開前に転送対象を確認してください。元のJPEG、README、テストは転送対象に含めません。
