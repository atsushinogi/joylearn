# 呪術廻戦で学ぶ漢字53問

`my-hero-academia` と同じフォルダー構成にまとめた既存教材です。32漢字・53通りの読みを53問で扱い、名前が問題文に現れる人物は30人です。

## 開く・ダウンロードする

- [問題と画像の一覧](exports/v1/index.html) ／ [問題](exports/v1/問題.md) ／ [解答](exports/v1/解答.md)
- [PNG一括](exports/v1/images-png.zip) ／ [WebP一括](exports/v1/images-webp.zip)
- [問題と画像の対応CSV](exports/v1/問題と画像の対応.csv)

PNG・可逆WebPは各53枚、すべて200×200pxです。IDと画像名はヒロアカ側と同じ `q001`〜`q053` に統一しました。問43は従来の採用稿 `q43-v2` に対応します。

## 保存内容

- `originals/`：採用原画53枚と問43の不採用初稿。
- `research/`：元教材の読み、既存の出典・人物・場面メモ、移行元の問題台帳。
- `review/`：200pxの確認シートと移行時の検証結果。
- `exports/v1/`：配布画像・問題・解答・CSV・一覧・ZIP・台帳。
- `workbook.json`：問題・読み・人物・場面・画像の対応台帳。
- `image-prompts.json`／`generation-history.json`：採用画像の生成入力と既存の生成・修正履歴。
- `review-observations.json`：既存の場面メモとファイル照合結果。

## 元教材の範囲と今回の確認

既存教材はアニメ第1期・第2期を中心とし、読み取り問題と語句補足を含みます。[出典と区分](research/出典と出題配分.md)を参照してください。今回の作業は構成整理です。台帳の内容審査欄は既存記録の引継ぎとして記載しており、新たな全編調査・内容再審査を行ったという意味ではありません。

53問の対応、全53読み、採用画像、寸法、PNGとWebPの復号画素一致、元画像とのバイト一致、リンクとZIP整合性を確認しました。配布画像・原画・生成履歴はこのフォルダーにまとめています。従来の問題ファイルからの案内リンクも更新しています。
