# 作品で学ぶ漢字・イラスト教材

元教材の読みを落とさず、作品の実際の人物・設定・場面から自然な書き取り問題と挿絵を作る。問題数・元教材・作品名・対象範囲・学年・サイズを既存の依頼から確認する。未指定なら、元教材にある異なる「対象漢字×辞書形の読み」ごとに1問、画像は200×200px、PNGと可逆WebPを作る。必要な入力だけを質問し、それに依存しない抽出・調査は進める。

## 維持する条件

- 全対象の読みを出題する。漢字の種類が一致するだけでは網羅にならない。元教材の語の読みと、各字の音訓・辞書形を区別する。
- **問題文に登場する異なる人物数を `ceil(問題数 × 0.6)` 以上**にする。53問なら32人以上。別名・変身・幼少期・操縦者とその分身は同一人物として集計する。名簿や画像にだけ登場する人物、名前の羅列による水増しは数えない。
- **指定した作品の全編を調査し、冒頭・中盤・終盤と主要編から偏りなく出題する。** 作品名だけを知っていることや、序盤の公式あらすじだけを読んだことを、全編の詳細把握と呼ばない。
- 原作と映像化の版、過去と現在、本人と体を借りた別人を区別する。架空の出来事を実際の場面として扱わない。
- **試作・本生成・内容修正は内蔵のimagegenを使う。** 形式変換の補助コードを絵の生成に代用しない。未承認のCLI/APIや別モデルに切り替えない。
- 問題・解答・出典・登場人物・プロンプト・採用画像を全件照合し、既知の不一致を直してから完成とする。ファイル検査だけでは内容確認の代わりにならない。

## 1. 読みの台帳を作る

[読みと調査の手順](references/research-and-readings.md)を読み、元教材を保全して候補を抽出する。

```bash
python3 scripts/workbook.py extract 元教材.json --output 読み候補.json
```

JSON・CSV・ルビ付きテキストの候補抽出を補助する。ルビのない漢字の読み、熟語内の各字の読み、送りがなの辞書形は自動では確定しない。原画像・読み一覧・辞書を照合し、確認した対象だけを `targets` に確定する。問題数を先に固定した場合も、対象読みの脱落で合わせない。

## 2. 全編を調査して配分する

公式の巻・章・話数一覧を起点に、対象範囲の全単位を列挙する。各単位の出来事、登場人物、時期、場所、設定、資料の到達度を記録する。終了済み作品は最終話まで、連載・放送中は確認日時点の公開済み範囲まで。原作を希望されたらアニメの公開済み部分だけに狭めない。

詳細資料を確認できない単位は `summary_only` / `unavailable` として残す。未確認を含む調査は完成と報告しない。人物数が不足する作品や、問題数より主要編が多い場合も、条件の未達を明示し、人物を捏造したり作品の範囲を黙って狭めたりしない。

主要編の長さに応じて出題数を配分し、全体を時間順に5分割した範囲にも分散する。人物一覧から必要人数を先に選び、無関係な人物を一文に詰めず、場面と役割を割り当てる。

## 3. 問題を確定する

[データ仕様](references/data-contract.md)に従い `workbook.json` を作る。各問に読みID、穴埋め、解答、解答入り全文、人物ID、場面ID、根拠を持たせる。原則1問1空欄。解答語は読みを維持して変更できる。読みの活用・促音・連濁は根拠を記録し、誤った読みで無理に字を使わない。

実際の場面・設定を使う。場面の解釈や語源学習でしか作れない対象は、代わりの場面や語を全編から探す。補足問題へ変更する必要があれば、ユーザーの条件との違いを示す。キャラクターの口調を優先して不自然な日本語や誤った熟語にしない。

```bash
python3 scripts/workbook.py hashes workbook.json --output fingerprints.json
python3 scripts/workbook.py validate workbook.json --stage text
```

読み・自然さ・作品との一致を実際に読み、各問の観察記録と現在の指紋を `review.text` に記録する。`hashes` は指紋を出すだけで、合格を付ける機能ではない。

## 4. imagegenで全件生成・修正する

[画像の制作と照合](references/images-and-review.md)を読む。imagegenスキルが利用できれば、その手順も適用する。サイズに合う構図を先に設計し、人物の特徴・時期・衣装・人数・動作・表情・小道具を必須特徴にする。200pxでは大きい顔と動作、少ない背景、文字なしを基本とする。

1問につき1回の生成入力を使い、生成した原画を出力作業フォルダーへ保存する。実際に使った入力と原画の来歴を保存する。修正版は別ファイルにし、旧稿と参照画像を保全する。

**すべての画像を開き、問題文・場面・必須特徴と一件ずつ比較する。** 一覧で判別できない細部は原寸で開く。対峙を集合写真にした絵、時期違いの衣装、別人、欠けた人物、誤った道具などはimagegenで修正し、再確認する。確認していない項目へ一括で合格を付けない。入力を後から書き換えて、作成済み画像と合うことにしない。

## 5. 検証してPNGとWebPを書き出す

```bash
python3 scripts/workbook.py validate workbook.json --stage images
python3 scripts/workbook.py export workbook.json --output exports/v1 --size 200
```

補助コードは読みの網羅、人数、全編の調査台帳、場面配分、確認指紋、画像対応を検査する。原画・問題・プロンプトが変わったら確認をやり直す。書き出しは機械的な縮小・形式変換のみ。正方形でない構図を無断で切り抜かない。出力先は新しいディレクトリにし、PNGと可逆WebPのサイズと全ピクセル一致、ファイル・対応表・一覧の一致を検査する。

未確認・不一致が残るときは部分成果と残件を示す。完成時は、読みの網羅率、問題数、必要人数と実人数、全編調査と配分、修正・確認の結果、PNG/WebP・一覧・生成指示の保存先を簡潔に伝える。公開・FTP同期・既存教材の置換は依頼範囲に含まれる場合だけ行う。
