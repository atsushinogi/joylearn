# 社会 第9回 江戸幕府クイズ

[クイズを開く](index.html) ／ [トップページ](../../index.html)

社会 第7回のクイズアプリをもとに、作成済みの50問と照合済みの148px WebP画像200枚を組み込みました。出題・選択肢のシャッフル、正誤表示、回答後の解説、得点、全問一覧、再挑戦に対応しています。各問にジョーク解答が1つあります。

教材とアプリはこの第9回ディレクトリに統合しています。元教材は [一行問題.txt](一行問題.txt)・[文字起こし.md](文字起こし.md)、問題集は [四択問題50問.md](四択問題50問.md) です。問題文・選択肢・正解・解説と画像の内容は保持しています。重複した問題データと未使用の画像制作中間ファイル・アーカイブは削除しました。

`quiz-data.js` と `choice-images.js` の行・選択肢位置を対応づけてからシャッフルします。画像のパスはFTP同期が検出できるようリテラルで列挙しています。アプリの配信用ファイルはHTML1個、JavaScript3個、WebP200枚です。

検証済み：JavaScript構文、全50問の正解・ジョーク各1つ、全200枚の画像形式・寸法・元画像とのバイト一致、トップページとアプリの相対リンク、FTP同期対象への全画像の収録。DOM代替環境では50問通しの満点・0点、画像と選択肢の対応、二重回答防止、未回答での次問遷移防止、解説、全問一覧、タブのキーボード切り替え、再挑戦のリセットを確認しました。

この実行環境にはブラウザーがないため、ブラウザーでの表示確認は未実施です。2026年10月31日にHPサーバーへ公開し、トップ・アプリ・画像の全205ファイルを公開URLからHTTP取得して、ローカルのSHA256との一致を確認しました。WebP200枚も全件確認済みです。

公開先：[江戸幕府クイズ](https://www.asahi-net.or.jp/~fk5a-ng/quiz/social-studies-2-lesson9/) ／ [トップページ](https://www.asahi-net.or.jp/~fk5a-ng/)

転送・配信確認の記録は `deployment.json` に保存しています。
