# デフォルメSVG 10枚（HP未公開）

`poketyping/pokemon_svg` にあるWebP由来のSVGを直接変形した、256×256pxの塗り絵風イラストです。頭と上半身を大きく、下半身を小さくし、元のSVGの色分けを維持しました。外周は丸みのある輪郭線、内側は主な色面だけに線を付けています。以前の128×128pxの試作10枚は、この10枚に置き換えました。

`preview.png` では各カードの左が元のSVG、右が新しいSVGです。
