## HPサーバーとのファイル同期

[ftp-sync.py](ftp-sync.py)を使い、このディレクトリ以下の対象ファイルをHPサーバーへアップロードします。Python 3の標準ライブラリだけで動作し、追加パッケージは不要です。

| 項目 | 設定 |
| --- | --- |
| 接続先 | `netftp.asahi-net.or.jp` |
| ユーザー | `fk5a-ng` |
| ポート | `21` |
| 転送先 | `homepage/` |

### 転送対象を確認する

このREADMEがあるディレクトリで実行します。接続せずに転送先と対象ファイルの一覧を表示します。

```sh
python3 ftp-sync.py
```

### アップロードする

```sh
python3 ftp-sync.py --upload
```

端末でFTPパスワードを入力します。入力内容は画面に表示されず、スクリプトにも保存されません。

ローカルの相対パスを保ち、必要な転送先ディレクトリを作成します。毎回、対象ファイルをすべて転送し、同名のファイルを上書きします。差分だけの転送ではありません。サーバー側だけにあるファイルは削除せず、サーバーからのダウンロードも行わない、一方向の同期です。ローカルで移動・削除したファイルの旧版はサーバーに残るため、必要に応じて別途整理してください。

### 転送対象と除外ルール

HTML（`.html`・`.htm`）、JavaScript（`.js`）、CSS（`.css`）を転送します。これらのファイル内のリテラルなパスから参照される画像・フォント・音声・動画・JSON・WebAssembly・JavaScriptモジュール（`.mjs`）・テキスト（`.txt`、問題ファイルやライセンス）なども対象です。外部URLは対象外で、動的に組み立てるパスは自動検出できません。

ドットで始まるファイル・ディレクトリ、`__pycache__`、シンボリックリンクは除外します。README、Markdown・Word文書、Python・CommonJSの開発用スクリプト、未参照のJSONなどは転送しません。開発セッション記録（Word・Markdown）も対象外です。

転送対象はGitの追跡状況や `.gitignore` とは独立して決まります。`dist/` 内の公開用ファイルも転送します。アップロード前に一覧を確認してください。

### FTPSを使う場合

通常のFTPでは認証情報と転送内容が暗号化されません。サーバーが明示的FTPSに対応している場合は、次のように `--tls` を追加できます。サーバーの対応状況は未確認です。

```sh
python3 ftp-sync.py --upload --tls
```

既存の簡易手順は [FTP-SYNC.md](FTP-SYNC.md) にもあります。
