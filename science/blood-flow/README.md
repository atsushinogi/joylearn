# 血液の旅

参考画像 `IMG_4034.heic` の血液循環図をもとにした、血管名を当てはめる学習アプリです。

## 使い方

`index.html` をブラウザーで開くだけで使えます。インストールやビルドは不要です。

ローカルサーバーを使う場合は、このフォルダーで次を実行します。

```sh
python3 -m http.server 8000
```

ブラウザーで `http://localhost:8000/` を開きます。

- 名前を選び、図の空欄をタップして配置します。空欄を先に選ぶ操作や、マウスによるドラッグにも対応しています。
- 入れた名前は変更できます。使用済みの名前を別の記入済み空欄に入れると、2つの名前が入れ替わります。
- 「答え合わせ」で正解と間違いを確認し、何度でも直せます。「ヒント」は選択中の空欄、または未正解の空欄について表示します。
- 「おぼえる」では、名前を選んで血液の流れる向きや血管の役割を確認できます。問題の回答はモードを切り替えても保持されます。
- 「解説をあてる」では、参考画像にある6つの解説文を、対応する血管の欄に配置します。パソコンでは名前の下、スマートフォンでは図の下の一覧に解説欄を表示します。採点・ヒント・答えの表示・やり直しに対応し、名前8問と解説6問の回答は別々に保持されます。
- 「参考画像を見る」で元の写真を表示します。ブラウザー用に変換した画像は `assets/reference.jpg` にあります。
- 「濃淡クイズ」では、6枚の循環図のうち、正しい3枚に「酸素」「養分」「不要物」を1つずつ当てはめます。残り3枚は空欄が正解です。選択肢の移動・入れ替え・取り外し、採点、ヒント、拡大、解答表示に対応しています。
- 濃淡クイズは初回表示時と「新しい6枚」を押すたびに図の順番をランダムに並べ替え、直前と同じ順にはしません。新しい出題では3つの回答を消します。通常のモード切替では濃淡クイズの回答と並びを保持します。
- 濃淡は同じ色（標準は緑）の明るさで示します。数値や実測濃度ではありません。食後を想定し、養分はブドウ糖など、不要物は尿素を表します。3枚の正解図は肺での酸素の受け取り、門脈の養分、腎静脈での尿素の減少を区別します。3枚のひっかけ図は、この3つの成分のどれにも当てはまりません。
- 濃淡クイズの「血流の色」で緑・青・赤・紫・グレーを選べます。「好きな色」では任意の色を選べ、「コントラスト」で薄い部分と濃い部分の差を調節できます。設定は6枚の図・拡大図・凡例に即時反映し、回答や図の順番は変えません。「標準に戻す」で緑・75%へ戻ります。色とコントラストはブラウザーに保存し、次回も引き継ぎます（保存できない環境でも表示の変更は使えます）。
- 血管には常に一定色の輪郭線を描き、その内側の血液だけを濃淡で表します。毛細血管の部分にも輪郭を付け、血液が薄い色でも管のつながりが見えるようにしています。拡大図も同じ表示です。

対象は肺動脈・肺静脈・大静脈・大動脈・肝静脈・門脈・腎静脈・腎動脈の8種類です。模式図は画面内で描画しており、外部サービスや外部フォントを使いません。

解説文は画像どおり、肺動脈「二酸化炭素が多く酸素が少ない。」、肺静脈「酸素が多く二酸化炭素が少ない。」、肝静脈「ほぼ一定の養分がふくまれる。」、門脈「食後、養分が最も多い。」、腎静脈「不要なものが最も少ない。」、腎動脈「不要なものが多い。」の6つです。

## ファイル

- `index.html`：画面と血液循環のSVG図
- `style.css`：パソコン・スマートフォン用の表示
- `app.js`：問題データ、配置操作、採点、解説
- `concentration-core.js`：6枚の濃淡パターン、ランダム出題、3つのラベルの移動と採点
- `concentration-quiz.js`：濃淡クイズのSVG図、選択肢、操作
- `assets/reference.jpg`：参考画像のブラウザー表示用コピー

JavaScriptの構文確認：`node --check app.js`

濃淡クイズの回帰テスト：`node --test tests/*.cjs`

ブラウザーの回帰テストは `tests/browser.py` です。開発用にPlaywrightをインストールして実行します（アプリの利用には不要です）。

```sh
python3 -m pip install playwright
python3 -m playwright install chromium
python3 tests/browser.py
```

解説6問の配置・入れ替え・採点・ヒント・答え表示・リセット、名前問題との回答の独立性、学習モード、タッチ操作、画面幅320〜1000pxの表示を確認します。公開先を検証するときは、環境変数 `BLOOD_FLOW_TEST_URL` にアプリのURLを指定できます。

濃淡クイズのブラウザーテストは `python3 tests/concentration_browser.py` です。正しい3枚と空欄の3枚の採点、ラベルの入れ替え・取り外し、連続出題時の並び替え、モード切替での回答保持、スマートフォンの操作を確認します。
