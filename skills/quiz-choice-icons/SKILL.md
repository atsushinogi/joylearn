# クイズ選択肢アイコン

問題と選択肢の対応を保ち、各選択肢を正しく表す画像と検証記録を作る。画像の主題・人数・小道具・動作の一致を確認し、既知の不一致を修正してから採用する。

**試作・本生成・再生成・参照編集は、最初からimagegenを使う。** SDXLは、今回の依頼でユーザーが明示的に指定した場合だけ使う。既存のSDXLコードやモデル、過去の制作記録があるだけでは、SDXLを使う指定とみなさない。

実施時は [共通手順書](references/workflow.md) を読む。データの準備、生成記録の形式、確認・修正の進め方、補助コマンドをまとめてある。

## 最初に固定するもの

- 問題データ、問題数、各問の選択肢数、出力先、ユーザー指定の生成方法とサイズを確認する。既存のコード・画像・ログがあれば利用する。
- この制作例の既定値は50問×4択、原画1024×1024 PNG、配布用148×148 PNG/WebP、写真リアル中心。別の指定があればそちらを優先する。
- `q01_a` のように、問題番号と元の選択肢位置からIDを付ける。画面上のランダムな並び順や、複数の意味で再利用される既存のアイコンキーをIDにしない。
- 描く対象は**その選択肢**。問題文は時代・意味の文脈として使う。誤答の選択肢まで問題の正解を描いたり、正解だけを目立たせたりしない。

## 設計と生成

1. 各IDに日本語の場面、画風、描写必須の特徴、避ける要素、文字の扱いを定義する。確認できる具体的な特徴を `required_features` に置き、必須のものを `critical: true` にする。
2. imagegenで、難しさの異なる数枚を試作する。重要な特徴と148pxでの識別性を確認してから、同じimagegenで残りのIDを本生成する。先にSDXLで全件を作る工程は設けない。
3. 不一致の修正もimagegenで行う。同じ不具合が続く方法で全件の再生成を繰り返さない。構図の簡略化や参照編集など、原因に合う修正へ切り替える。imagegenが利用できない場合は自動でSDXLへ切り替えず、利用できないことと代替案を伝え、抽出・設計など実行できる作業を進める。
4. 実際に送った最終入力・回避事項・バックエンド・設定を生成時に保存する。imagegenで生成・編集した画像は `generation_backend: "imagegen"` と記録する。指定していないシードや不明な内部モデル名を推測して記録しない。ユーザーが別方式を明示指定した場合はその方式を使い、実際の方法を記録する。
5. 原画を所定のPNGサイズへ正規化し、正しい生成メタデータを保存してから目視確認する。修正候補は別フォルダに置く。

歴史上の合戦では、ユーザーが集団戦を求めていれば、両軍の多数の兵と交戦の動作を必須条件にする。単独武将、行進、整列だけでは合格にしない。写真・漫画・作品の撮影表現などは題材に合わせ、不要な細部を盛り込んで識別に必要な特徴を弱めない。

## 全件の照合と修正

- 一覧画像を `view_image` などで開き、**全IDを一件ずつ**、問題・選択肢・設計指示・実際の生成入力と比較する。小道具・文字・弦や孔の数などが曖昧なら原寸を開く。
- 各必須特徴について、画像内の観察事実を記録する。テンプレート生成やファイル検査だけで画像を確認済みにしない。
- `pending` は未確認、`mismatch` は具体的な不一致あり、`aligned` は主要要件を確認、`limited` は主要要件を満たすが史実の厳密な再現などには確認の限界あり。**既知の失敗を `limited` に言い換えない。**
- 必須特徴の欠落、人数の誤り、別の楽器、違う服装、不要な可読文字、指定した全体像の切れなどは、対象IDの候補を再生成または参照編集して直す。編集対象はツールで事前に目視し、元画像と編集前の参照画像を残す。
- プロンプトを直した場合は、その入力で画像を作り直す。既存画像に合わせて「実際に生成に使った入力」を後から書き換えたり、未使用の入力をPNGメタデータに入れたりしない。
- 修正後は画像と指示の両方を再照合し、確認したPNGのSHA256と指示のSHA256を記録し直す。ファイルが変われば以前の確認結果を流用しない。
- 同じ修正が改善しない場合は、残りの時間・費用・ユーザー指定を踏まえて方法を見直す。利用可能で許可された方法では要件を満たせない画像は不一致・未採用として明示し、完成と報告しない。追加のユーザー判断が本当に必要な事項だけ確認する。

ここでの確認記録はCodex自身が行う目視照合であり、定型的なユーザー承認を追加する手順ではない。

## 書き出しと完了

`scripts/quiz_icons.py` は、データ抽出、確認用一覧、記録・PNGの検査、確認済み画像の書き出しを行う。画像生成や画像内容の認識は行わない。

書き出す前に全IDの確認を終え、未確認・既知の不一致・必須特徴の未確認がないことを検査する。原画は残し、修正で使った元画像・参照画像・プロンプト・旧書き出しも保管する。既存の配布先を更新する場合は退避を先に完了する。

今回の標準書き出しは1024 PNG・148 PNG・148 WebPと3つのZIP。縮小はLanczos、WebPはquality 85 / method 6。別サイズの依頼では設定と検査を合わせ、固定プロフィールの補助コードをそのまま流用しない。

完了時は、画像数、修正数、出力先、実際の生成方法、原画像の保存先、検査結果、確認の限界を簡潔に伝える。「ファイル検査に合格」と「画像の意味が完全に正しい」を混同しない。画像制作の依頼を、未依頼のサイト公開や外部同期へ広げない。
