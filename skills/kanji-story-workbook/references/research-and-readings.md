# 読みの抽出と作品全編の調査

## 読みを取りこぼさない

元教材の「読む」「新しい漢字」「書く」、ルビ、解答、欄外の読みを確認する。問題文だけに読みがない場合、画像・解答・付随一覧を先に探す。ユーザーが対象字を指定していれば、その字の教材に示された全読みを採用する。教材外の難読・名乗りを勝手に追加しない。対象範囲が「漢字を含む全文の全読み」なら、書き取り空欄だけに狭めず、全文を語・字へ対応付けて台帳を作る。

候補抽出の優先順位は、明示的な対象字・辞書形の読み一覧、答えとルビの対応、語の読み、未確定の空欄。形態素解析器を使う場合も、辞書の版と結果を残し、人名・連濁・活用を確認する。正答のない `〔かな〕` から漢字を推測して確定しない。

各対象に固定IDを付ける。例えば `得／トク` と `得／える` は別IDであり、同じ字を出すだけでは両方を満たさない。`独／ひとり` のような特殊な読み、`在り` と辞書形 `ある`、`持て余す` と `あます`、`仏教` と `ブツ→ぶっ` の対応も個別に根拠を残す。ひらがな・カタカナの差だけで別の読みを水増ししない。

必要項目は `kanji`、辞書形の `reading`、音訓などの `reading_type`、元の語と語全体の読み、元教材の位置、確認に使った根拠。語を構成する各字へ分割できない候補は、語のまま未確定にする。OCRの異体字・読み違い・脱字は原画像に戻って直す。原文と正規化後の値を両方残す。

## 全編の範囲を固定する

先に公式目次や公開話数一覧から `expected_unit_ids` を作る。巻全体の概要だけで章ごとの詳細調査を済ませない。単位は原則、原作は話・章、アニメは話。長い1話や章は場面単位の補足ノートを追加できる。

- 作品名、版、媒体、最終話または公開済みの終点、調査日、目次の出典を記録する。
- 漫画とアニメを両方参照する場合は各単位へ媒体と番号を付け、対応関係を持たせる。重複する話を二重に数えて「全体」を偏らせない。
- 各話について出来事の順序、誰が誰に何をしたか、場所、時期、人物の状態、使用した能力・道具、前後の理由と結果を残す。
- 全文・本編や十分詳しい信頼できる資料で確認できたものを `detailed`、短いあらすじしか確認できないものを `summary_only`、資料に到達できないものを `unavailable` とする。
- 公式あらすじは有力な出典だが、それにない細部まで確認したことにしない。原作・公式設定集・公式の場面解説を優先し、補足資料で確認した部分は区別する。
- 読めない単位、矛盾、推測を残し、未確認のまま「全編を詳細に把握した」と報告しない。アクセスできる資料を整理する作業は続ける。

全編を一度にモデルの文脈へ詰め込まず、編・巻ごとに調査して台帳を保存し、共通の時系列・人物表へ統合する。後半の人物や能力は調査後に台帳へ追加する。既知の序盤キャラクターだけから全問を作り始めない。

## 全体から出題する

`segments` は全対象単位を時系列順に重複なく覆う主要編・まとまりとする。小編を都合よく合併して偏りを隠さない。単位数に比例した配分を計算し、問題数が主要編数以上なら各編から最低1問を出す。検査用の配分からの差は原則±1問まで。さらに全単位を時間順に5等分し、全区間に最低1問を配置する。5問未満の教材では問題数に合わせて等分する。

```bash
python3 scripts/workbook.py plan workbook.json
```

問題の性質と作品の構成に合わず配分を変える場合、理由を台帳へ記録し、変更条件をユーザーと合わせる。序盤だけを使ったまま配分欄を埋めない。問数が主要編数より少なく、全編からの出題を満たせない場合は問題数・範囲の調整が必要な状態として示す。

人物は固定IDと別名一覧で管理する。同一人物を別の役職・変身・時期・機体名で数えない。別個の人物が同じ体を使う場合は、作品上の実体と場面の時期で区別する。「一般人」「店員」「母」などの匿名役や、術者が出す式神を人数条件の埋め合わせに使わない。マスコットなど作品内で独立した人格・役割を持つ登場人物は、根拠を確認して採用できる。
