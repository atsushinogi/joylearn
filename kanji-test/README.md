# かんじのテスト室

「もじのアトリエ」とは別の、ブラウザ内で動く漢字テストアプリです。ビルドやAPIキーは不要です。手書き認識エンジンは Kanji Canvas を再利用し、このアプリだけを公開しても動くように `dist/vendor/` に同梱しています。元のアプリは変更しません。

## 使い方

`dist/index.html` を開き、問題集を複数選択 → 問題数を指定 → テストを開始します。指・ペン・マウスで1文字ずつ書き、認識候補を選んで回答欄に追加します。熟語は1文字ずつ追加します。キーボードからも回答・訂正できます。複数の空欄がある場合は、回答したい欄を選んでください。

前後の移動、問題一覧からの移動、未回答のまま先に進む操作に対応しています。最後に「採点する」を押すと、得点・正解・自分の回答を一覧表示します。間違えた問題だけの再テストもできます。回答や結果は保存しません。

採点は、候補で確定した文字／キーボードで入力した文字と正解の一致で判定します。前後・途中の空白と全角半角の互換表記は正規化します。異体字・別解の自動判定や、筆跡の字形・書き順の採点は行いません。1問1点、複数空欄は全空欄の正解で1点です。100点満点への換算は四捨五入します。未回答は不正解です。

## 問題ファイルの追加・編集

1. `dist/questions/` に UTF-8 の `.txt` ファイルを置きます。サブディレクトリは使いません。
2. 1行1問で書き、空欄にしたい漢字を `（ ）` または `( )` で囲みます。熟語・短文・複数の空欄に対応します。
3. 必要なら、問題文の後に **実際のタブ文字** を入れて読みを書きます。複数の空欄は、タブ区切りで空欄の順に読みを書きます。読みは省略できます。
4. このディレクトリで `node scripts/build-questions.cjs` を実行します。問題の検証と一覧の再生成を行います。
5. ページを再読み込みします。公開時は更新した `dist/` 一式を配置してください。

例（下記の問題文と読みの間はタブです）：

```text
# オリジナルの問題集
友達に（謝）る。	あやま
新しい（技術）を学ぶ。	ぎじゅつ
（規）則を守り、順（序）よく並ぶ。	き	じょ
自然の（豊）かさを感じる。
```

`#` 行の最初の行が問題集の表示名になります。空行と `#` で始まる行は問題として数えません。BOM付きUTF-8、LF・CRLF・CR改行に対応します。かっこ内は漢字のみで、送り仮名はかっこの外に書きます。閉じ忘れ・空のかっこ・漢字以外の正解などは、ファイル名と行番号を表示して生成を止めます。

1ファイルの問題数に固定の上限はありません。出題数は選択ファイルの合計から重複を除いた数まで指定できます。複数のファイルに同じ問題文があるときは1問にまとめます。最初のファイルの読みを使用します。ファイルごとの等分抽出ではなく、選択した全問題をまとめて、重複しないようランダム抽出します。

静的サーバーはディレクトリ内のファイル一覧を自動取得できないため、生成コマンドで `question-bank.js` と `questions/index.json` を作ります。`question-bank.js` は問題ファイルから生成された配信用データです。直接編集せず、元の `.txt` を編集してください。ネット接続なしでHTMLを直接開く場合も、この生成済みデータで動きます。

## サンプル

学校と学び／自然と科学／社会とくらし／ことばの力、各15問、計60問です。空欄内の漢字を小学5年生の配当漢字に限定しています。文中の空欄以外は他学年の文字を含みます。

配当の出典：文部科学省「小学校学習指導要領（平成29年告示）解説 国語編」、学年別漢字配当表、第5学年193字（冊子193ページ、PDF197ページ）。
https://www.mext.go.jp/content/20220606-mxt_kyoiku02-100002607_002.pdf#page=197

## 検証

```sh
node scripts/build-questions.cjs
node --test tests/*.cjs
node --check dist/app.js
node --check dist/ink-pad.js
```

入力・認識とテスト進行を分離しています。`dist/core.js` が問題解析・重複除去・抽出・採点、`dist/ink-pad.js` が手書き、`dist/app.js` が画面と進行です。
