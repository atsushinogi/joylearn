# 僕のヒーローアカデミアで学ぶ漢字53問

kanji-50 の32漢字・53通りの読みを、原作本編の人物・設定・場面を使った53問にしました。問題文に役割を持って登場する異なる人物は46人です。別名・変身・分身・成長後の姿を重複人数に数えていません。

## 開く・ダウンロードする

- [画像付き一覧](exports/v1/index.html)：全53問、解答の開閉、PNG/WebPの個別保存。
- [問題](exports/v1/問題.md) ／ [解答](exports/v1/解答.md) ／ [対応CSV](exports/v1/問題と画像の対応.csv)
- [PNG一括](exports/v1/images-png.zip) ／ [WebP一括](exports/v1/images-webp.zip)
- [200px確認シート1](review/200px-sheet-1.png) ／ [2](review/200px-sheet-2.png) ／ [3](review/200px-sheet-3.png)

配布用画像はPNG・可逆WebPとも各53枚、縦横200×200pxです。解凍後は対応CSVのIDと画像名を合わせて使います。一覧の画像を押すと生成原画を開けます。

## 対象範囲と資料の確認方法

対象は堀越耕平による原作コミックス本編全42巻、第1〜431話です。最終巻の描き下ろし「More」を含み、映画・外伝・ファンブックの追加短編は含めません。23の主要編と、全体を時系列で5分割したすべての範囲から出題しています。

全431話の詳細な公開二次解説を確認し、公式巻一覧、人物設定、アニメ公式の場面紹介を併用しました。**原作全巻を直接閲覧した記録ではありません。** [章別確認メモ](research/章別確認メモ.md)、[出典と配分](research/出典と出題配分.md)、[詳細台帳](workbook.json)に確認箇所と資料の到達度を残しています。

## 挿絵と検証

内蔵imagegenで制作し、53件すべてを問題・解答・人物・時期・動作と照合しました。13件の採用画像は初稿から修正しています。すべてを200×200pxの実寸でも確認しました。原作のコマの複写ではなく、場面や設定を学習用に再構成した挿絵です。流血は避け、回想・象徴表現は実際の出来事と区別しています。

[生成入力](image-prompts.json)、[生成・修正履歴](generation-history.json)、[個別の観察記録](review-observations.json)、[検証結果](review/image-check.json)を保存しています。生成入力では文字なしを指定し、レビューでは正規衣装の校章・体操着模様だけを許容しています。解答や問題の文章は絵に入れていません。

`originals/` は原画と修正前の候補、`exports/v1/` は配布版です。PNGとWebPの復号画素の完全一致、寸法、53件の対応、一覧リンク、ZIP整合性を検査しています。配布版にも確認用の原教材読み一覧・出典メモ・生成入力を同梱しています。

この教材は `kanji-50/my-hero-academia/` 内にまとめてあり、呪術廻戦の教材・画像とは別のフォルダーです。
