# 岩の標本室

参考画像 `IMG_4035.heic` に載っている岩石の写真に、名前と解説文を当てはめる静的学習アプリです。堆積岩6種類（泥岩・砂岩・礫岩・石灰岩・チャート・凝灰岩）と変成岩2種類（大理石・粘板岩）の、名前8問と解説8問を学べます。

## 使い方

`index.html` をブラウザーで開くと使えます。ビルドやインストール、ネット接続は不要です。

- 空欄を選んで、対応する名前や解説文を選びます。パソコンでは選択肢を先に選ぶ操作と、同じ種類の欄へのドラッグも使えます。
- スマートフォンでは空欄をタップすると選択肢が開きます。画面下からも選択肢や答え合わせを開けます。
- 配置済みの選択肢も移動できます。2つの記入済みの欄では回答が入れ替わります。選択中の欄を空にすることもできます。
- 「答え合わせ」は名前と解説を別々に採点します。ヒントと、不正解・未回答の欄へ移動するボタンもあります。
- 「おぼえる」では正しい名前・解説・分類・できかたを表示します。問題に戻ると自分の回答が残っています。
- 写真の拡大、参考画像の表示、答えの表示、確認付きのリセットに対応しています。

## ファイルと検証

- `rocks.js`：画像の8種類の名称・解説・ヒント
- `quiz-core.js`：回答の配置、入れ替え、クリア、16問の採点
- `app.js`：画面と操作
- `assets/sample-01.webp`〜`sample-08.webp`：参考画像から名前が入らないよう切り出した8枚の写真
- `assets/reference.webp`：ブラウザー表示用の参考画像

```sh
node --check app.js
node --check rocks.js
node --check quiz-core.js
node --test tests/*.cjs
```

ブラウザーの回帰テストは `tests/browser.py` です。開発用のPlaywrightとChromiumを導入して実行します（アプリの利用には不要です）。

```sh
python3 -m pip install playwright
python3 -m playwright install chromium
python3 tests/browser.py
```

16問の採点、配置・入れ替え・クリア、学習モード、リセット、写真の拡大と参考画像、種類を区別したドラッグ、スマートフォンの選択画面、幅320〜1280pxの表示を検証します。`ROCK_TEST_URL` で確認するページのURL、`ROCK_SCREENSHOT_DIR` でスクリーンショットの保存先を指定できます。

ローカルサーバーを利用する場合は、このフォルダーで `python3 -m http.server 8000` を実行し、`http://localhost:8000/` を開きます。

公開時はHTML・CSS・3つのJavaScript・`assets/` の9枚のWebPが必要です。元のHEIC、README、テストは公開用ファイルではありません。写真のファイル名はデータ内に記載しているため、FTP転送前に9枚が含まれることを確認してください。
