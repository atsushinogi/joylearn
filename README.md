## HPサーバーとのファイル同期

[ftp-sync.py](ftp-sync.py)を使い、このディレクトリ以下の対象ファイルをHPサーバーへアップロードします。Python 3の標準ライブラリだけで動作し、追加パッケージは不要です。

| 項目 | 設定 |
| --- | --- |
| 接続先 | `netftp.asahi-net.or.jp` |
| ユーザー | `fk5a-ng` |
| ポート | `21` |
| 転送先 | `homepage/` |

### 転送対象を確認する

このREADMEがあるディレクトリで実行します。接続せずに転送先と対象ファイルの一覧を表示します。

```sh
python3 ftp-sync.py
```

### アップロードする

```sh
python3 ftp-sync.py --upload
```

端末でFTPパスワードを入力します。入力内容は画面に表示されず、スクリプトにも保存されません。

ローカルの相対パスを保ち、必要な転送先ディレクトリを作成します。前回のアップロード以降に追加・変更されたファイルだけを転送します。比較には `.ftp-manifest.json`（前回転送したファイルのパス・サイズ・SHA256）を使い、転送が成功したファイルを記録します。途中で接続が切れた場合は自動で再接続し、中断した場合も次回は未転送のファイルだけを送ります。サーバーからのダウンロードは行わない、一方向の同期です。

| オプション | 動作 |
| --- | --- |
| （なし） | 接続せずに、転送予定のファイルと公開対象から外れたファイルを表示 |
| `--upload` | 変更・追加されたファイルだけを転送 |
| `--upload --full` | 全対象ファイルを転送（サーバーを手作業で変更した後など） |
| `--upload --delete-removed` | 転送に加え、前回転送したが公開対象から外れたファイルをサーバーから削除し、空になったフォルダも削除 |
| `--record-only` | 接続せずに現在の対象ファイルを `.ftp-manifest.json` に記録（サーバーが既に同じ内容の場合） |
| `--list` | 転送予定だけでなく全対象ファイルを表示 |

`.ftp-manifest.json` がない場合は全ファイルを転送します。`ftp-sync.py` 以外でサーバーを変更すると記録と実際がずれるため、その後は `--full` で転送してください。`--delete-removed` を付けない場合、公開対象から外れたファイルはサーバーに残ります。

### 転送対象と除外ルール

HTML（`.html`・`.htm`）、JavaScript（`.js`）、CSS（`.css`）を転送します。これらのファイル内のリテラルなパスから参照される画像・フォント・音声・動画・JSON・WebAssembly・JavaScriptモジュール（`.mjs`）・テキスト（`.txt`、問題ファイルやライセンス）なども対象です。外部URLは対象外で、動的に組み立てるパスは自動検出できません。

ドットで始まるファイル・ディレクトリ、`__pycache__`、シンボリックリンクは除外します。README、Markdown・Word文書、Python・CommonJSの開発用スクリプト、未参照のJSONなどは転送しません。開発セッション記録（Word・Markdown）も対象外です。

転送対象はGitの追跡状況や `.gitignore` とは独立して決まります。`dist/` 内の公開用ファイルも転送します。アップロード前に一覧を確認してください。

### 接続方式と1ファイルだけの更新

この接続先では通常のFTPを使用します。2026年10月28日に確認したところ、明示的FTPSの `AUTH TLS` は `502 Command not implemented` で利用できませんでした。通常のFTPでは認証情報と転送内容が暗号化されません。

トップページの `index.html` だけを更新する場合は、[FTP-SYNC.md](FTP-SYNC.md) の個別アップロード手順も使えます。`ftp-sync.py --upload` でも、変更が `index.html` だけならその1ファイルだけを転送します。
