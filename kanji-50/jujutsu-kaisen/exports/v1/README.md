# 呪術廻戦漢字53問・配布版

[問題と画像の一覧](index.html) ／ [問題](問題.md) ／ [解答](解答.md)

- 32漢字・53通りの読みを扱う53問、問題文に現れる異なる人物は30人。
- PNGと可逆WebPは各53枚、すべて200×200px。
- ファイル名は `q001`〜`q053`。問43は旧版の `q43-v2` に対応する修正版です。
- 既存の問題文・採用画像を移行し、画像のバイト一致、PNG/WebPの復号画素一致、寸法、リンク、ZIP整合性を検査しました。

## ファイル

`originals/` は採用原画、`png/` と `webp/` が配布画像です。一覧の表示・保存はWebPを使い、画像を押すと200×200pxのWebP画像を開けます。

[PNG一括](images-png.zip) ／ [WebP一括](images-webp.zip) ／ [対応CSV](問題と画像の対応.csv)

[台帳](workbook.json) ／ [生成入力](image-prompts.json) ／ [画像対応表](manifest.json) ／ [検証結果](validation.json)
