# 社会 第10回 4択問題データ

[一行問題.txt](一行問題.txt) の全60問から、正解1つ・不正解3つ、計240選択肢を作成しました。元の番号・順序・解答を保持し、漢字を含む選択肢には読みを、全問に回答後の短い解説を付けています。

誤答には関連する人物・出来事・制度などを選び、同義語や正解の別名が別の選択肢に入らないようにしています。正解の位置は1〜4番に各15問ずつ分散しています。

## データ形式

各問は `id`（元の番号）、`q`（問題文）、`options`（4つの選択肢）、`explanation`（解説）、`source`（元問題の参照）を持ちます。

各選択肢の `label` は表示文字列、`furigana` は読みです。カタカナだけの選択肢では読みを省略しています。`correct: true` の選択肢が1つだけあり、不正解の選択肢では `correct` を省略しています。CSVの正解位置は **1始まり** です。

アプリ側で選択肢を並べ替える場合は、`label`・`furigana`・`correct` を同じオブジェクトとして移動してください。既存の画像付きアプリに組み込む場合は、対応する選択肢画像と画面側の設定を別途用意します。
