# 三角形の比ラボ

三角形ABCのAD・BE・CFが1点Pで交わるとき、2つの辺の分割比から残りの分割比を求める4択練習アプリ。

- 基本：面積比の共通項が同じ数になっている問題。
- 応用：共通項を最小公倍数（12以下）にそろえる問題。両方の比を整数倍する必要がある。
- 毎回ランダムに5問出題。同じ回の問題と、直前の同レベルの5問は重複しない。
- 求める比もAF : FB・BD : DC・CE : EAからランダムに選択。1回の5問で3辺すべてが登場し、各辺1〜2問ずつ出題する。
- カーソル・キーボードフォーカスで候補の比を図に仮表示し、クリック・Enter・Spaceで採点。
- 比の各値を、対応する線分BD・DC・CE・EA・AF・FBの中央付近に表示。求める辺の「？」も仮表示・採点に合わせてそれぞれ更新。
- ヒント、各問の解説、5問の結果、再挑戦に対応。

ビルド不要。`index.html`をブラウザで開くか、このディレクトリで `python3 -m http.server 8000` を実行して `http://localhost:8000/` を開く。親のjoylearnから配信する場合は `/ratio/`。

検証：`node --test tests/*.cjs`。外部APIや保存用サーバーは不要。
